Sign in to read the documentation and try the endpoints.

The seeded accounts are in the README. Signing in here is the same request the application makes: POST /api/auth/signin.

Every endpoint here is live against the running stack, authorized as . Nothing to paste: the token from signing in is already filled in.
Authorize offers a second scheme, apiKey. It is only for POST /api/v1/findings, the endpoint scanners and CI pipelines use. Mint one at POST /api/api-keys and paste it there; leave it empty otherwise.
